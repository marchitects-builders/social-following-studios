in its frame with no code change.

Shoot notes: photograph each class three quarters front, outdoors, in even light, with the
whole vehicle in frame and room around it so the crop holds at every screen size. Export at
1600px wide or larger. Filenames in `src/data.js` under `FLEET[].photo` if these change.
